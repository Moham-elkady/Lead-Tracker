# Lead-Tracker
A simple and practical Chrome Extension built with JavaScript to save tabs and useful links quickly.  This project started as a way to practice JavaScript and ended up becoming a real extension that can actually be used in daily browsing.  Features: - Save current tabs - Save custom links - Store data using localStorage - Simple and clean UI

# Lead Tracker Chrome Extension

A simple Chrome Extension built with JavaScript to save tabs and useful links quickly.

## Features
- Save current tab
- Save custom links
- Delete all saved leads
- Local storage support

## Technologies
- JavaScript
- HTML
- CSS
- Chrome Extension APIs

## How to Run
1. Download the project
2. Open chrome://extensions
3. Enable Developer Mode
4. Click Load Unpacked
5. Select the project folder
